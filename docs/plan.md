# 中文教材辅导的 AI 可靠性实验场：方向与四周试验（2026-10-14）

本页记录 2026-10-14 确认的方向和第一个试验。它不是已完成能力清单；数据契约与命令见 [README](../README.md)。
本仓库从 [dotty-tutor](https://github.com/ningkaikok/dotty-tutor) 拆分而来：dotty 保留为演示应用和回归基线，实验在这里独立进行。

## 1. 定位

以中文教材辅导为场景的 **AI 可靠性实验场**：每次实验回答一个具体问题，产出数据、方法、典型失败案例和工程改进，
目标是让别人能复现、能用来改进自己的系统。项目不转型为“评测榜单”，也不以模型强弱排序为主要成果。

dotty-tutor 的学习应用（教材课件、错题陪练、掌握度与复习）保留为演示外壳和回归基线，暂缓扩展；实验中验证有效的做法再以小改动回流到 dotty。

## 2. 为什么不是“中文辅导榜单”

公开工作已经覆盖了大部分直观空白（2026-10-14 核实）：

| 已有工作 | 覆盖内容 |
| --- | --- |
| [TutorBench](https://arxiv.org/pdf/2510.02663)（Scale，[榜单](https://labs.scale.com/leaderboard/tutorbench)） | 1,490 个辅导案例，其中 828 个带图（含手写作答），专家 rubric，持续榜单 |
| [MMTutorBench](https://arxiv.org/abs/2510.23477) | 685 道多模态数学辅导题，并比较 OCR 管线对辅导质量的影响 |
| [FACTS Grounding](https://arxiv.org/abs/2501.03200) | 回答是否受给定文档支持 |
| [DeepTutor](https://arxiv.org/abs/2604.26962) | 基于课程来源的交互评测 |
| [EduBench](https://arxiv.org/pdf/2505.16160)、[EduEval](https://arxiv.org/pdf/2512.00290)、[SID](https://arxiv.org/pdf/2508.04563) | 中文/双语教育场景、K12 认知层级、中文苏格拉底式对话 |

因此“中文 + 图片 + 持续榜单”不构成优势。尚待验证的切入点是：

> **中文教材存在缺页、错公式、图文冲突时，辅导系统能否识别证据问题，并给出恰当的讲解或请求补充材料？**

这与 dotty-tutor 已有积累一致（OCR 公式发布保护、来源复核、无证据不引用），但仍需实验证明，不宣称无人做过。

## 3. 第一个试验问题

同一道题在 **原图 / 正确转写 / 损坏转写** 三种输入下，**直接看图的模型** 与 **OCR + 文本模型** 分别在哪里出错？
加入来源检查后，能减少多少错误判断，又增加多少成本？

## 4. 四周试验

| 周 | 内容 | 产出 |
| --- | --- | --- |
| 1 | 选一个初中数学主题（建议含公式和图，如一次函数图像或相似三角形），编写 30–50 道原题并人工核对；生成扰动变体 | 原题 JSONL、变体 JSONL、核对记录 |
| 2 | 先列出模型、调用次数与预估费用并由用户确认；然后对比少量模型与两条输入管线 | 原始运行结果 |
| 3 | 按原题分组分析：识别错误、推理错误、引用是否支持结论、证据不足时的处理；检查裁判与人工抽检的一致性 | 失败模式清单与典型案例 |
| 4 | 写成可复现报告，请少量外部开发者或有学科能力的人复现、挑错 | 报告与外部反馈 |

数据规则：

- 只需要人工核对原题；变体由 `zh_tutor_reliability.variants` 按锚点确定性生成，缺陷位置由构造决定。
- 同一原题的变体按 `itemId` 分组分析，不当成独立证据。
- 干净变体上的误报和拒答要计分，“全部拒答”不能得高分。
- 30–50 题的规模只用于探索，不支持正式排名。正式结论仍需独立复核（至少两人独立评审、盲评），不放松。
- 可公开的案例必须自编或采用开放许可；教材原页只用于本地实验。学生作答图片需自行准备。

## 5. 四周后的去留判断

满足以下条件，值得继续投入：

- 至少 2 个失败模式能在多个模型上复现，并且能解释原因；
- 干净材料上的作答能力没有因为保守拒答而明显下降；
- 至少 1 个外部的人按文档跑通案例，或愿意用这些案例检查自己的系统。

如果只得到模型强弱排序，且评分主要依赖作者本人判断，就保留为个人实验工具，不再扩建评测平台。
